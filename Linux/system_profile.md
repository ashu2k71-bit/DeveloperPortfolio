## Binary Number Representation

### Decimal 75 to binary

| Division | Quotient | Remainder |
| --- | ---: | ---: |
| 75 / 2 | 37 | 1 |
| 37 / 2 | 18 | 1 |
| 18 / 2 | 9 | 0 |
| 9 / 2 | 4 | 1 |
| 4 / 2 | 2 | 0 |
| 2 / 2 | 1 | 0 |
| 1 / 2 | 0 | 1 |

Reading the remainders from bottom to top gives **1001011**.

Therefore, **75 in decimal = 1001011 in binary**.

Check: 64 + 8 + 2 + 1 = 75.

### Binary 110101 to decimal

110101 = (1 × 2^5) + (1 × 2^4) + (0 × 2^3)
       + (1 × 2^2) + (0 × 2^1) + (1 × 2^0)

= 32 + 16 + 0 + 4 + 0 + 1
= **53 in decimal**.

### Why computers use binary

Digital circuits use two distinguishable voltage ranges to reliably represent the binary digits 0 and 1.
